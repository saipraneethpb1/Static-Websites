# 🌐 Static Websites Collection

A collection of beautifully designed static websites built using **HTML5** and **CSS3** as part of frontend web development practice.

This repository showcases multiple mini-projects including landing pages, UI layouts, informational websites, media pages, booking pages, and interactive navigation-based websites.

# 📌 About The Project

This repository contains a variety of static website projects created to strengthen frontend development fundamentals and improve UI design skills.

The projects focus on:

- Clean webpage structuring
- Modern UI design
- CSS styling techniques
- Layout creation
- Navigation between sections/pages
- Responsive-like layouts using containers and positioning
- Real-world website cloning & inspirations

These projects were built mainly using concepts learned through **CCBP 4.0 Academy (NxtWave)**.

# 🚀 How To Run The Project

## Clone the Repository

```bash
git clone https://github.com/saipraneethpb1/Static-Websites.git
```

## Navigate Into the Folder

```bash
cd Static-Websites
```

## Open Any Project

Open the desired project folder and run the `index.html` file in your browser.

Example:

```bash
cd Food-Order-Page
```

Then open:

```bash
index.html
```
